 Key Changes
Express v4 (Stable): Downgrade from Express v5 to v4 (widely adopted, battle-tested)
JWT Authentication:
jsonwebtoken package for token generation/verification
On signup/login → returns JWT token
auth.middleware.js verifies token on protected routes
Token payload: { id, email } signed with secret from .env
Input Validation: Using joi library for schema validation
Error Handling: Custom AppError class + global error handler middleware
Separation of Concerns:
Routes only define endpoints & middleware chain
Controllers handle request/response, delegate to services
Services contain business logic & database calls
Validators define input schemas
Bug Fix: Fix the login double-response bug (missing return on password mismatch)
